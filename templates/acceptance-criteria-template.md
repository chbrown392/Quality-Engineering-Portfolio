# Acceptance Criteria Template

## Scenario — [Business behavior]
**Given** [starting state / role / precondition],  
**When** [user or system action],  
**Then** [observable expected result],  
**And** [additional result, data persistence, permission, or downstream behavior].

## Coverage prompts
- Positive path
- Negative path
- Permissions/role path
- Conditional logic
- Data persistence
- Error/fault handling
- Regression impact
